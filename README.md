# MS AI Certification Quiz

A comprehensive practice quiz platform for Microsoft AI-900 and AI-102 certifications.

## Features
- 🎯 AI-900 (Azure AI Fundamentals) & AI-102 (Azure AI Engineer) question banks
- 📝 Multiple choice & multi-select question types
- ✅ Instant feedback with correct answers and explanations (Chinese translations included)
- 📚 Wrong answer collection with export to Markdown
- 📊 Scoring system with pass/fail threshold
- 🎲 Mock exam simulation mode

## Tech Stack
- TypeScript + React 18
- Static deployment via GitHub Pages

## Getting Started
```bash
npm install
npm run dev
```
